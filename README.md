# SimplePad 
Простой текстовый редактор написанный с помощью фреймворка **QT**. Для написания использовалась **IDE** ***Visual Studio*** с расширением ***QT Visual Studio Tools***. Возможно использование систему сборку **QMake** для ***Qt Creator***, для этого в каталоге с исполняемыми файлами имеется файл **SimplePad.pro**.  
Работаспособность проекта проверена в **ОС** ***Windows 11x64*** с использованием **IDE** ***Qt Creator*** и ***Visual Studio***.
## Сборка проекта
Для сборки и запуска проекта нужно чтобы у вас был установлен фреймворк **Qt**, при необходимости скачайте с **офф. сайта**. 
### Сборка и запуск для Visual Studio
 В **IDE** ***Visual Studio*** во вкладке **Расширения** выбрать пункт **Управления расширениями**, в открывшемя окне на вкладке **В сети** в потсковом окошке введите название расширения ***Qt Visual Studio Tools***, после скачивания и установки прийдётся перезагрузить ***Visual Studio*** с выбором в появившемся окне **Modify** и дождаться конца установки. После перезапуска выберете вкладку **Расширения->Qt Vs Tools->Qt Versions**, в окне выберите версию фреймворка **Qt** указав расположения ***qmake*** утилиты. Что то вроде:  **Расположение Qt->version->используемый компилятор->bin->qmake**. После этого в корне папки проекта откройте SimplePad.sln, в свойствах проекта на вкладке **Свойства конфигурации->QtProjectSettings**  в строке **Qt Installation** выберите свою версию фреймворка. После этого у вас должен успешно скомпилироваться проект.
### Сборка и запуск для QtCreator
В ***Qt Creator*** нажмите на кнопку **Open Project** выберите файл **SimplePad.pro** который находится в проекте вместе с исходными файлами, сконфигурируйте проект и запустите нажав кнопку **Запустить** или сочитание клавишь ***"Ctrl + R"***.
